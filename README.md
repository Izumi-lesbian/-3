# ASDOM Official Website

A minimalist, text-only website starter for *Average School Days Of Mine*.

## Files
- `index.html` — website content
- `style.css` — colours, typography and layout

## Publish with GitHub Pages
1. Create a new GitHub repository named `ASDOM-Website`.
2. Upload `index.html` and `style.css` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub Pages will provide the published website address.

The download section intentionally says **Coming soon**. Add official Ren'Py game download links only when a release build is ready.

## Customisation
Edit the text in `index.html`. Change the colour variables near the top of `style.css` to adjust the theme.
